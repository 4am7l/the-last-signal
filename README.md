# الإشارة الأخيرة

محاكاة ثلاثية الأبعاد للقمر والمريخ مع استكشاف السطح. يتضمن الأرشيف سجل إيغل وصور أبولو 11.

## التشغيل

    npm ci
    npm run dev

    npm test
    npm run build

## إيغل

- [سجل ناسا NSSDCA، المعرّف 1969-059C](https://nssdc.gsfc.nasa.gov/nmc/spacecraft/display.action?id=1969-059C).
- [إحداثيات LROC](https://lroc.im-ldi.com/data/support/downloads/2016_LROC_Coordinates_of_Human_Features.pdf): 0.67416° شمالًا، 23.47314° شرقًا.
- [مجسّم NASA / Michael D. Carbajal](https://science.nasa.gov/3d-resources/apollo-lunar-module/). تعرض المحاكاة الوحدة القمرية كاملةً كما ظهرت وقت الهبوط، بامتداد 9.4 م بين القدمين المتقابلتين.
- الصور من سجل NSSDCA و[أرشيف ناسا لأبولو 11](https://www.nasa.gov/wp-content/uploads/static/history/ap11ann/kippsphotos/apollo.html).

## خرائط الأجرام

- القمر: [NASA CGI Moon Kit · LROC / LOLA](https://svs.gsfc.nasa.gov/4720/).
- المريخ: [NASA/JPL-Caltech/USGS Viking planetary mosaic](https://science.nasa.gov/3d-resources/mars/).

تستخدم شاشة المعاينة مقياس عرض موحّدًا. التفاصيل الصغيرة قرب نقطة النزول توضيحية.
