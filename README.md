# الإشارة الأخيرة — تحديث القصة والحركة

## التشغيل من المصدر
ثبّت Node.js ثم نفّذ داخل المجلد:

    npm install
    npm run dev

لإنشاء نسخة توزيع:

    npm run build

هذه الحزمة تحتوي المصدر المحدّث والأصول. لا تحتوي dist القديمة لأنها لا تمثل هذا التحديث.

## ما تغيّر
- بقاء مساحة الرسم ثابتة، وانتقال كاميرا مستقل عن تحديثات الوقت؛ تحكم المستخدم يوقف التوجيه التلقائي.
- أبعاد مختلفة للمركبات حسب القياسات المنشورة، ومقياس سطح بالمتر ونظرة أبعد.
- الصاروخ والحماية في العبور، ومراحل دخول ومظلة وهبوط مختلفة حسب المهمة.
- تمثيل وسائد MER الهوائية، ونزول إنسايت، وحاملة إنجينيويتي والرافعة السماوية، وصعود أبولو.
- شريط تحريك لكل مشهد، وسرعات تشغيل، وفصول حسب السنوات ورسائل سرد عربية.
- تحميل كل أصل منفصلاً حتى لا يختفي المشهد بالكامل أثناء تحميل مجسّم.

## تحديث أطلس الكواكب
خرائط ناسا للقمر، ارتفاعات LOLA، غلاف جوي بصري للمريخ والأرض وغيوم أرضية، 12 ألف نجمة، وعلامات بإحداثيات الهبوط مع إخفائها خلف الجرم. اختيار الموقع ثم زر النزول يفتح المعدات وسط تضاريس ممتدة 24 كم بدلاً من المنصة السابقة. لا يمثل هذا انتقال LOD جغرافي متصلاً أو مسحاً حقيقياً للتضاريس المحلية.

التفاصيل والمقارنة بين المكتبات ومصادر الأصول في [وثيقة البنية](docs/PLANET-ARCHITECTURE.md).

## حالة التحقق
نجح `npm run build` وفحص الإحداثيات `node tests/coordinates.test.mjs`. جرى التحقق من ملفات الصور محلياً. تعذّر الاختبار البصري ثلاثي الأبعاد لأن متصفح الفحص يعطّل WebGL؛ لم يتم تأكيد العرض أو الأداء على الهاتف.

## حدود الدقة
مجسّمات المعدات الأصلية من NASA/JPL. الصواريخ والأغلفة والحاملة والرافعة والقاعدة المتبقية لأبولو نماذج تعليمية مبسطة وليست أصول NASA تفصيلية. الحركة والارتدادات ليست محاكاة فيزيائية أو بيانات SPICE. عمليات التجوال والطيران توضيحية، وليست مسارات فعلية مقاسة. مجسّم إنجينيويتي الأصلي يصور الحالة قبل تلف الشفرات.
إحداثيات الهبوط موثقة بالمصدر والمرجع. بعض الإحداثيات النهائية الدقيقة والمسح الطبوغرافي الحقيقي لم تُدمج. الصور والخرائط الرسمية منفصلة عن الأرضية التوضيحية. لا تتعامل مع المشهد كخريطة ملاحة دقيقة.
الملخص السنوي يروي السنة كاملة؛ وضعه في بداية السنة على شريط التنقل ليس تاريخ وقوع كل أحداثها. الرسائل إعادة سرد وليست اقتباسات من اتصالات المهمة.
