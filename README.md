# الإشارة الأخيرة — تحديث القصة والحركة

## واجهة المستكشفين من عمر 8 إلى 16 سنة
- ألوان بنفسجية ونعناعية وبرتقالية في الوضعين الفاتح والداكن، وخط أكبر وأزرار مناسبة للمس.
- رسومات SVG محلية للمقدمة والقمر والمريخ، مع تمييز الرسومات التوضيحية عن صور NASA.
- شرح مختصر أولًا، وتفاصيل علمية يمكن فتحها عبر «اعرف أكثر»، ودليل بداية مع قاموس صغير للمصطلحات.
- الخطوط محلية بصيغة WOFF2، والأيقونات SVG لا تعتمد على خدمة خطوط خارجية. تراخيص الخطوط في `public/fonts/`؛ مصدر الخطوط [Google Fonts](https://github.com/google/fonts).
- تبقى نماذج المهمات والمحاكاة والبحث والتصفية والمصادر العلمية كما هي.

لتعديل ألوان هذه الواجهة وأحجامها استخدم `src/youth-theme.css`؛ النصوص والتقسيمات في `src/Experience.tsx`، والرسومات في `public/illustrations/`.

## التشغيل من المصدر
ثبّت Node.js ثم نفّذ داخل المجلد:

    npm install
    npm run dev

لإنشاء نسخة توزيع:

    npm run build

هذه الحزمة تحتوي المصدر المحدّث والأصول. لا تحتوي dist القديمة لأنها لا تمثل هذا التحديث.

## ما تغيّر
- بقاء مساحة الرسم ثابتة، وانتقال كاميرا مستقل عن تحديثات الوقت؛ تحكم المستخدم يوقف التوجيه التلقائي.
- أبعاد مختلفة للمركبات حسب القياسات المنشورة، ومقياس سطح بالمتر ونظرة أبعد.
- الصاروخ والحماية في العبور، ومراحل دخول ومظلة وهبوط مختلفة حسب المهمة.
- تمثيل وسائد MER الهوائية، ونزول إنسايت، وحاملة إنجينيويتي والرافعة السماوية، وصعود أبولو.
- شريط تحريك لكل مشهد، وسرعات تشغيل، وفصول حسب السنوات ورسائل سرد عربية.
- تحميل كل أصل منفصلاً حتى لا يختفي المشهد بالكامل أثناء تحميل مجسّم.

## تحديث أطلس الكواكب
يتيح الأطلس الآن **القمر والمريخ فقط**؛ أزيلت الأرض ومجسّمها وملفات خامتها السحابية. تُعرض خرائط الكواكب وارتفاعات القمر وغلاف المريخ مع علامات مواقع الهبوط. عند اختيار جرم أو مهمة جديدة يظهر مؤشر تحميل بأسلوب Material 3 Expressive إلى أن تُحمّل الخرائط ومجسّم المهمة وتُرسم الإطارات الأولى؛ لا يعتمد الاختفاء على عدّاد وهمي. قد تستمر التحسينات الاختيارية للصور والتضاريس بعد ظهور المشهد. الحفر والصخور المحلية إعادة بناء تعليمية وليست مسحًا دقيقًا.

التفاصيل والمقارنة بين المكتبات ومصادر الأصول في [وثيقة البنية](docs/PLANET-ARCHITECTURE.md).

## حالة التحقق
نجح `npm run build` ونجحت اختبارات `npm test` الـ18 بعد تحديث الواجهة. جرى فحص الرئيسية والأرشيف والدليل بعروض 320 و390 و768 و1440 بكسل، والوضعين الفاتح والداكن، والبحث والتصفية وفتح التفاصيل. حُمّل مشهد القمر ثلاثي الأبعاد في Chromium بنجاح. هذا فحص متصفح آلي، وليس قياس أداء على هواتف فعلية.

## حدود الدقة
مجسّمات المعدات الأصلية من NASA/JPL. الصواريخ والأغلفة والحاملة والرافعة والقاعدة المتبقية لأبولو نماذج تعليمية مبسطة وليست أصول NASA تفصيلية. الحركة والارتدادات ليست محاكاة فيزيائية أو بيانات SPICE. عمليات التجوال والطيران توضيحية، وليست مسارات فعلية مقاسة. مجسّم إنجينيويتي الأصلي يصور الحالة قبل تلف الشفرات.
إحداثيات الهبوط موثقة بالمصدر والمرجع. بعض الإحداثيات النهائية الدقيقة والمسح الطبوغرافي الحقيقي لم تُدمج. الصور والخرائط الرسمية منفصلة عن الأرضية التوضيحية. لا تتعامل مع المشهد كخريطة ملاحة دقيقة.
الملخص السنوي يروي السنة كاملة؛ وضعه في بداية السنة على شريط التنقل ليس تاريخ وقوع كل أحداثها. الرسائل إعادة سرد وليست اقتباسات من اتصالات المهمة.
