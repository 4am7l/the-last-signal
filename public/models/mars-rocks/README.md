# Mars rock models — source and licence

The following ten 3D rock meshes are included as **GLB files** in this folder:

- rock-largea.glb, rock-largeb.glb, rock-largec.glb, rock-larged.glb, rock-largee.glb, rock-largef.glb
- rock-talla.glb, rock-tallb.glb
- rock-smallb.glb, rock-smallc.glb

Original assets: **Kenney — Nature Kit**  
https://kenney.nl/assets/nature-kit

Downloaded from the public GLB mirror: **Hidencod/tge-assets**  
https://github.com/Hidencod/tge-assets/tree/main/packs/nature-kit

**Licence: Creative Commons CC0 1.0 Universal (public domain).**  
https://creativecommons.org/publicdomain/zero/1.0/

The original model silhouettes are authored 3D meshes, not astronomical measurements or surveyed Mars rocks. The website rescales, refines, instantiates and re-shades them for a cinematic Martian appearance. Variations, landing-site placements and colours are illustrative, not reconstructions of mission photographs. These files are bundled locally so visitors do not depend on third-party model CDNs.
